# Versus

Multiplayer battles for Geometry Dash (Geode mod `tipp7.versus`): 1 vs 1 and Group rooms, Ranked, LIVE spectating.

## Download

**[Latest release](https://github.com/Rlaxogus123/Geode_Versus/releases/latest)**: download `tipp7.versus.geode`
(Windows, macOS, iOS and Android in one file) and put it in Geometry Dash's Geode mods folder (`geode/mods`).
Versus keeps itself up to date after that.

Releases are published automatically from the game's own update server, so the latest release here is always
the version players are on. This repository holds release builds only.
